# Postman y Newman

La colección está en `postman/SIGEFLOT.postman_collection.json`. Postman permite ejecutar solicitudes manualmente; Newman las ejecuta en terminal. Copie el environment de ejemplo a un archivo local ignorado y ejecute `cd postman; npm install; npm run test:api`. Las variables son `base_url`, `email`, `password`, `access_token` y `vehicle_id`; los secretos solo van en el environment local.
